# 홈 푸터 정원 버전

- **1번 — 작은 정원:** 사용자가 마음에 들어 한 첫 버전. 통통한 새·긴 귀 토끼·안테나 로봇, 꽃·바람개비.
- **2번 — 작은 숲 소풍:** 둥근 곰·고양이·걸어 다니는 버섯, 작은 벤치·나무·클로버.

각 번호 폴더의 `garden.html`과 `homeGarden.css`가 해당 디자인의 보관본이다. 특히 **1번은 원본 그대로 보존**하며 새 버전을 덮어쓰지 않는다.

프로젝트 루트에서 적용한다.

```bash
node scripts/set-footer-garden.js 1
node scripts/set-footer-garden.js 2
```

명령은 `public/index.html`의 정원 부분과 `public/css/homeGarden.css`만 바꾼다. 다른 헤더·푸터·명함 코드나 데이터는 건드리지 않는다. 적용 후 브라우저를 새로고침한다.

사용자가 **“1번으로 해”, “1번으로 되돌려”**라고 하면 1번 적용 명령을 실행한다. 현재 적용한 번호는 인계 문서의 최신 기록을 확인한다.
