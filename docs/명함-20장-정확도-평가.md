# 명함 20장 정확도 자체 평가

## 1. 테스트 환경

- 테스트 일자: 2026-08-06
- 실행 환경: macOS 개발 PC, Node.js 로컬 서버, SQLite
- AI 실행 환경: LM Studio, `qwen3.5-9b-mlx`
- 테스트 방식: 명함 이미지를 한 장씩 `/api/cards/extract`에 전달한 뒤 원본 이미지와 추출 결과를 직접 비교
- 판정 기준: 명함에 없는 필드를 빈 값으로 반환한 경우도 정답으로 계산하고, 글자·숫자의 누락이나 다른 필드로의 잘못된 분류는 오답으로 계산

### 처리시간 및 안정성

- 분석 성공: 10/10장 (100%)
- 평균 처리시간: 67.0초
- 최소 처리시간: 50.2초
- 최대 처리시간: 80.8초
- 1분 이내 처리: 4/10장 (40%)

분석 실패는 없었지만 평균 처리시간이 1분을 넘었으므로, 현재 상태에서는 한 장 처리 1분 이내 요구사항을 충족하지 못한다.

## 4. 현재 확인된 개선 과제

- 누락 필드 재확인 과정 때문에 일부 명함에서 Local AI 요청이 두 번 실행되어 처리시간이 길어질 수 있다.
- 한글 한 글자와 영문 이름 철자처럼 모양이 비슷한 문자를 잘못 읽는 경우가 있다.
- 중국 휴대전화와 여러 국가의 국제전화 분류·형식 보존을 보강해야 한다.
- 홈페이지의 하이픈, 주소의 우편번호·층수, 여러 국가의 지점 정보를 빠뜨리는 경우가 있다.
- 사람 이름이 없는 회사 공용 명함에서 `name`을 빈 값으로 유지하는 검증이 필요하다.

휴대폰 테스트 10장의 결과를 추가한 뒤, 20장 전체 기준으로 각 필드의 정답 수를 합산하여 최종 인식률을 계산한다.
