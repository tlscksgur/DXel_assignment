# 중복 후보 그룹 그리드 디자인

## 목표

중복 모아보기 화면에서 중복 후보 그룹을 세로 한 줄이 아닌 반응형 그리드로 표시한다.

## 디자인

- 그룹이 1개나 2개일 때는 전체 묶음을 가운데 정렬한다.
- 그룹을 한 줄에 최대 3개 표시하고, 4개부터 다음 줄로 넘긴다.
- 화면이 좁아지면 들어갈 수 있는 개수만 표시하고 자동으로 줄바꿈한다.
- 각 그룹은 동일한 높이로 강제하지 않고, 포함된 명함 수에 따라 아래로 확장한다.
- 그룹 내부의 명함 카드는 기존 `305px × 204px` 크기를 유지한다.
- 기존 그룹 제목, 개수 배지, 색상과 그림자는 유지한다.

## 구현 범위

- `public/css/BCM.css`: 중복 모드와 그룹 너비를 반응형 그리드로 변경한다.
- `test/card-management.test.js`: 3열·2열·1열 배치와 기존 카드 크기를 회귀 테스트한다.

## 성공 조건

- 그룹 1개와 2개가 가운데 정렬된다.
- 그룹 3개까지 한 줄에 표시된다.
- 그룹 4개부터 다음 줄로 내려간다.
- 명함 카드 크기는 계속 `305px × 204px`이다.
