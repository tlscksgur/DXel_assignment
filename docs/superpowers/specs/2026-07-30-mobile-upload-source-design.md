# 모바일 업로드 방식 선택 디자인

## 목표

휴대폰에서 명함 사진 업로드를 누르면 사진 촬영과 사진 선택 중 하나를 명확하게 고를 수 있게 한다.

## 동작

- 680px 이하에서는 업로드 버튼을 누르면 하단 선택창이 열린다.
- `사진 촬영`은 `capture="environment"` 입력을 실행한다.
- `사진 선택`은 다중 선택이 가능한 갤러리 입력을 실행한다.
- 선택창의 취소 또는 배경을 누르면 닫힌다.
- 데스크톱에서는 업로드 버튼을 누르면 기존처럼 파일 선택창을 바로 연다.
- 두 입력에서 받은 파일은 기존 연속 업로드 큐와 순차 분석 로직을 공유한다.
