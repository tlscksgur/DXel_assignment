# 모바일 반응형 디자인

## 목표

같은 로컬 네트워크로 접속한 휴대폰에서 홈, 명함 등록, 명함관리 화면을 가로 스크롤 없이 사용할 수 있게 한다.

## 디자인

- 900px 이하에서 명함 등록 화면의 사진 영역과 추출 결과 영역을 한 열로 배치한다.
- 680px 이하에서 헤더, 제목, 폼, 작업 버튼, 푸터의 여백과 글자 크기를 모바일에 맞춘다.
- 등록 폼은 모바일에서 한 열로 표시하며 입력 글자 크기는 16px 이상으로 유지한다.
- 홈의 최근 명함은 화면 너비에 맞추고 내부 연락처 정보는 줄바꿈한다.
- BCM 명함 카드의 기존 `305px × 204px` 크기는 유지한다.
- 기존 HTML과 JavaScript 기능은 변경하지 않는다.

## 검증

- CSS 회귀 테스트로 900px·680px 미디어 쿼리와 핵심 한 열 배치를 확인한다.
- 전체 Node 테스트로 업로드, Local AI, 상태 API, BCM 기능이 유지되는지 확인한다.
