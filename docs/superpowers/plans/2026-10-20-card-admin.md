# 명함 관리자 권한 및 XSS 점검

목표: 서버 설정으로 지정한 이메일의 인증된 계정만 전체 명함을 수정·삭제·복원하게 한다. 개인 즐겨찾기·그룹은 항상 로그인 사용자 기준으로 유지한다.

구조: `auth/card-access.js`의 공통 관리자 판정은 세션에서 확인한 사용자 이메일과 `CARD_ADMIN_EMAIL`을 비교한다. 서버의 변경 권한 검사, 목록의 `can_edit`, 휴지통 필터가 같은 판정을 사용한다. 가입·프로필 요청으로 관리자 이메일이나 권한을 바꾸는 API는 추가하지 않는다. 기본값은 관리자 없음이다.

- [x] `test/card-access.test.js`: 지정 계정의 단건·일괄 수정/삭제/복원 허용, 일반 계정 거부, 관리자도 출처 검사 유지, 임의 요청 본문으로 승격 불가를 먼저 확인한다.
- [x] `test/deployment-path.test.js`: 임시 DB의 실제 서버에서 관리자/일반 계정 목록 권한 및 휴지통, 개인 데이터 격리를 확인한다.
- [x] `auth/card-access.js`, `server.js`: 기존 권한 경로에 관리자 예외를 추가하고 즐겨찾기·그룹 SQL의 사용자 ID는 유지한다. `is_mine`을 분리하여 관리자의 내 명함 필터도 실제 등록자만 표시한다.
- [x] `.env.example`, `deploy/ubuntu.env.example`, `deploy/README.md`: 관리자 이메일 설정과 재시작 필요성을 한국어로 안내한다.
- [x] 공개 JS의 HTML/URL 출력, 업로드, 응답 헤더를 읽기 전용 보안 검토한다. 확인 범위에서 재현 가능한 XSS는 발견되지 않았다. CSP 추가 방어와 실제 배포 브라우저 침투 검증은 수행하지 않았다.
- [x] 전체 테스트 196개 통과, JS 문법 검사와 diff 검증 완료. 로컬 `.env`에 관리자 이메일을 지정했으나 실제 서버 설정/배포는 미수행이며 공개 HTTP 운영은 HTTPS 전환 필요.

새 의존성, DB 마이그레이션, 다른 사용자 개인 분류 조회, 임의 계정 관리 기능은 추가하지 않는다. 기존 사용자 변경은 보존한다. 커밋·푸시는 별도 요청 전 수행하지 않는다.
