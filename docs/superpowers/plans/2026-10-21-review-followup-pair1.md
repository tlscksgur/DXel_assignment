# 추가 리뷰 1·2번 수정

범위: 로그인/비밀번호 재설정 동시 처리와 삭제 완료 후 다른 편집창 닫힘만 고친다. 기존 모든 미커밋 변경은 보존하며 CSV 수식 주입과 vCard 종료 문자열 문제는 다음 묶음으로 남긴다.

- [x] 새 `test/login-password-race.test.js`에서 실제 로그인·재설정·비밀번호 변경 핸들러 사이의 순서를 통제해 기존 비밀번호로 세션이 뒤늦게 생기는 실패를 확인했다. 기존 4개 실패에서 수정 후 전부 통과했고 인증 해제·계정 삭제 경합도 보호한다.
- [x] `auth/routes.js`: 조건부 `INSERT ... SELECT`로 검증 당시 비밀번호 해시 및 현재 인증 상태를 세션 삽입 시점에 원자적으로 확인한다. 변경 건수 0이면 401이며 쿠키를 발급하지 않는다. 로그인 실패 제한 해제는 세션 발급 성공 후 수행한다.
- [x] `public/js/cardManagement.js`, 새 `test/card-delete-race.test.js`: 삭제 대상 ID와 현재 상세 DOM 문맥을 고정해 다른 명함/다시 연 편집창을 닫거나 오류 메시지로 덮어쓰지 않는다. 기존 6개 실패에서 관련 8개 모두 통과.
- [x] 전체 329개 테스트/JS 문법/diff 검사 통과, 독립 읽기 전용 검토에서 추가 차단 결함 없음. 실제 서버·브라우저 실기기 검증은 미수행. 커밋·푸시·배포 없음. 남은 항목: CSV 수식 주입, vCard 내용의 종료 문자열 인식 오류.
